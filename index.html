How it stays fresh

The update.yml workflow runs weekly, fetches airports.csv from the OurAirports project, regenerates the JSON and commits only when the data actually changed. GitHub Pages serves the result. No server to run.

Data source and accuracy

The source is the OurAirports data dump maintained by David Megginson, in the public domain. It is the successor to the open FAA database and is updated continuously from national registries. All 86,350 rows of the current dump are included: 42,790 small airports, 23,283 heliports, 13,659 closed facilities, 4,107 medium airports, 1,274 seaplane bases, 1,175 large airports and 62 balloon ports.

Limits, stated plainly

  • The full dataset is ~26 MB of JSON — use the per-country files or filter after fetching.
  • 13,659 records are marked closed; they are kept because historical references still resolve to them.
  • IATA/ICAO coverage is sparse by nature, so treat a null code as "none published", not an error.
  • Coordinates are single reference points — no runways, taxiways or frequencies are included.
